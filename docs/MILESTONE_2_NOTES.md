# Milestone 2 Evidence Notes

Milestone 2 intentionally tests **specificity as well as sensitivity**.

The corpus should fail if ADCP only learns to escalate. Ordinary fatigue, healthy withdrawal, figurative language, intact social support, and humor must remain distinguishable from accumulated distress patterns that warrant progressively stronger care.

A second invariant is now explicit: **a perfect deterministic fixture score is not evidence of clinical validity.** These fixtures are protocol-engineering artifacts. Their value is exposing implementation consistency, threshold boundaries, and failure modes before live inference is attempted.

The next research milestone should therefore test threshold stability and independent stage labeling before adding semantic observation inference.
